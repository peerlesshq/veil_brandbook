Template 03 / Positioning

Partnership Thesis

看见事件发生前 See Before it Happens

招商材料要把预测市场从“交易平台”表达成“内容、社区、活动、品牌和数据场景的连接器”。合作价值来自用户参与、话题运营和高质量市场信息，而不是单纯交易量叙事。

Template 05 / Partner Map

Who We Work With

把合作对象分成六类，避免招商页变成泛泛介绍。

每类伙伴都有不同目标：获客、内容、品牌、区域渗透、活动转化或企业服务。PPT 中应清楚说明对应权益和交付边界。

Media

内容和媒体机构

专题市场、联合栏目、数据图卡、热点评论。

Community

社群和 KOL

社群活动、教育内容、联合直播、增长任务。

Region

区域代理和城市伙伴

本地化市场、活动落地、渠道拓展和客户维护。

Event

赛事和活动主办方

赛前预测、现场互动、屏幕视觉、活动复盘。

Enterprise

企业和品牌客户

品牌议题、用户洞察、内容共创、合作专区。

Institution

研究和教育机构

市场机制教育、研究数据、讲座和公开课程。

Template 10 / Enablement Timeline

Partner Enablement

给合作方一条清晰的落地时间线。

招商 PPT 需要降低对方的执行不确定性。时间线应包含启动、物料、上线、复盘四个阶段，明确双方协作界面。

Week 01

Alignment

确认合作类型、目标人群、活动场景、市场主题和责任人。

Week 02

Asset Build

输出合作页、KV、社媒素材、市场说明和培训材料。

Week 03

Launch

联合发布、社群运营、活动引导、数据监控和问题响应。

Week 04

Review

复盘参与、内容表现、合作反馈和下一轮扩展计划。

Replace timeline with actual project rhythm when confirmed10

Template 11 / Light Color Standard

Color Standard - Light Trust

招商文件、合作说明和中文增长素材默认用浅色体系。

Light Trust 适合高频阅读、合同附件、合作手册、公众号文章和小红书图文。保持白纸感，减少视觉噪声。

56% White 18% Pearl 14% Ink 8% Jade 4% Gold

Primary

White / Pearl 承担大面积，让招商材料看起来可信、正式、可打印。

Action

Jade / Cobalt 只用于按钮、强调、流程节点和关键数据。

Premium

Gold 只用于合作等级、权益、邀请和官方背书。

Do not turn the whole deck green, blue, or gold11

Template 12 / Dark Color Standard

Color Standard - Dark Premium

发布会、展台主屏、合作封面和高级招商页使用深色体系。

Dark Premium 负责权威感和高价值传播。深墨是舞台，Jade/Cobalt 是信号光，Gold 只是少量资质高光。

64% Ink 14% Graphite 9% Jade 8% Cobalt 5% Gold

Use

封面、章节页、线下屏幕、主视觉、合作发布海报。

Pairing

白字 + Jade 信号 + 少量 Gold，避免彩虹光效和过度科技感。

Avoid

不要把深色页做成投资人路演式“宏大叙事”，招商仍要落地。

Dark mode is premium, not default document mode12

Template 14 / Next Steps

Formal Closing Content Page

最后一页内容页要让合作方知道下一步怎么推进。

不要以“期待融资”结尾，而是以“确认场景、对接团队、试点合作、复盘扩展”结尾。

    Confirm scenario
    选择内容、渠道、活动或企业合作方向。

    Assign owners
    确认双方负责团队、素材审批人和上线窗口。

  • C

    Run pilot
    以 2-4 周试点合作验证用户参与和内容表现。
