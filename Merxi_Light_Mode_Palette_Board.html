Light Mode Branding System

Merxi Pearl Signal Palette

一个面向亚洲高频移动用户、同时适合欧美金融科技市场的浅色品牌系统。核心是珍珠白、冰雾蓝、玉青、钴蓝和少量香槟金：清晰、可信、现代、克制，不博彩化，也不落入普通 Web3 霓虹风。

46%白色与近白表面，负责信任感和阅读效率
36%冰蓝与石墨层级，负责结构、边界和信息密度
16%玉青与钴蓝信号，负责品牌识别和交互行动
2%香槟金点缀，只用于高级感、合作和里程碑

01 Strategy

Light mode is the default trust surface.

预测市场的浅色界面不应该显得廉价或过度金融化。Merxi 的 Light Mode 要像亚洲头部券商和全球 fintech 的结合体：信息密度高、背景干净、信号明确，品牌高光集中在关键路径。

亚洲用户

偏好清晰层级、强可读性、较高信息密度和明确行动按钮。浅底减少长时间阅读疲劳，也更适合中文、日文、韩文排版。

欧美用户

需要避免“赌场感”和夸张 Web3 质感。白底、冷色、石墨文字和克制金属光可以更接近合规金融与研究产品。

品牌识别

钻石符号保留“折射、概率、信号”的概念。浅色模式中，钻石不靠黑底发光，而靠冰面、透明边缘和局部高饱和色形成记忆点。

商业物料

招商、线下展台、PPT 和社媒可以大量使用留白。品牌主色只在标题、按钮、曲线、标签、二维码边框和页脚系统中出现。

02 Core Palette

03 Light Tokens

04 Logo & Diamond

浅色里，钻石靠折射而不是重阴影。

Light Mode 的 Merxi mark 要保留同一套几何逻辑：四象限切面、玉青到钴蓝、少量香槟高光。应用上使用更干净的白底图标，避免在浅底上堆过重发光。

Light icon standard

图标底建议为 Pearl White 或 Porcelain，外框使用极浅冰蓝边界。钻石主体保持高透明晶体感，玉青和钴蓝负责识别，香槟金只作为右上切面或高光。

05 Product UI

高频界面：浅底、清线、强行动。

App 和 Web 产品是 Light Mode 的主场。列表、图表、行情、市场详情使用白底；状态变化用玉青和钴蓝表达；香槟金只出现在合作、评级、会员或里程碑，不用于日常交易判断。

Image2 product visual

适合官网产品页、招商材料、发布会 key visual。

Primary CTA

钴蓝用于强行动，玉青用于确认与已选。不要同时放两个同权重渐变按钮。

Market cards

白底卡片、冰蓝 hover、石墨标题、灰蓝辅助信息，让列表可快速扫描。

Charts

概率线优先用玉青与钴蓝。网格线低对比，避免红绿蜡烛图联想到投机。

Forms

输入框保持 Porcelain 底，focus 使用玉青边线和极轻发光。

06 Data & Semantics

预测市场不要默认红绿化。

亚洲金融界面常见红绿语义在不同地区含义会冲突。Merxi 的国际化默认方案使用玉青、钴蓝和石墨灰作为主判断色，只在风险提醒中少量使用珊瑚红。

Probability positive

Jade 用于支持、上升、确认、成交成功。它比纯绿色更品牌化，也更少带股市地域冲突。

Action and focus

Cobalt 用于主行动、当前路径、链接和关键指标。它提供全球化科技感，不会过度地域化。

Risk and alert

Risk 珊瑚红只用于错误、失败和强提醒。不要用于营销标题或主视觉，以免出现博彩或紧张感。

Chart pairing

  • 双线对比：Jade vs Cobalt。
  • 第三条辅助线：Slate 或 Champagne，不引入新高饱和色。
  • 置信区间：同色 10% 到 16% 透明度。
  • 极端风险：Risk 只标注阈值或 error state。

Localization

  • 中国、日本、韩国、新加坡和欧美版本可以保持同一套主色。
  • 农历新年、合作活动可以增加 Champagne 比例，但不把红金变成长期主色。
  • 英文、中文、日文和韩文界面都使用同样的表面与边线 token。
  • 地区差异放在图形节奏和文案语气，不放在核心品牌色。

07 Social & Campaign

社媒浅色版：留白就是高级感。

社媒内容要区别于普通 crypto 风格。Light Mode 的视觉重点是钻石、曲线、半透明 UI 和大量空白，适合 X、LinkedIn、微信公众号封面、小红书封面、招商邀请图。

08 Deck, Print & Offline

招商和线下物料要更像研究机构。

线下展台、招商手册、投资人 deck、易拉宝和会议屏幕可以使用更大留白和更少颜色。让品牌显得稳、贵、可信，而不是抢夺注意力。

Investor / Partnership Deck

看见事件发生前 See Before it Happens

招商、融资、BD 和活动首页推荐使用白底大图、单一主标题、少量玉青或钴蓝强调。

Print ratio

白底 62% / 冰蓝 20% / 石墨 12% / 品牌色 6%。香槟金仅用于页码、章节或 partner badge。

Deck

封面用浅色 key visual，内页用 Pearl White 和 Ice Surface。每页只保留一个品牌色焦点。

Booth

远距离识别靠钻石符号和钴蓝线条。展台墙面不铺满图案，保留干净白面。

Merch

白、银、冰蓝为主，图标可以局部烫银或局部 UV。避免大面积金色造成奢侈品或赌场联想。

09 Light Mode Rules

可复制的设计标准。

这套浅色系统可以直接作为 UI、营销和品牌团队的协作标准。核心判断：白底要干净，颜色要少，信号要准，钻石要像资产而不是装饰。

Do

Use restraint

  • 白底 + 冰蓝边线 + 石墨文字作为默认组合。
  • 用 Jade 表示品牌信号和确认，用 Cobalt 表示主行动。
  • 图像中保留真实留白，让标题、二维码、CTA 有稳定空间。
  • 跨亚洲和欧美市场保持同一套核心 token。
Don't

Avoid visual noise

  • 不要用红绿作为默认涨跌系统，国际化语义会冲突。
  • 不要大面积霓虹渐变、彩虹高光、币圈粒子和赌场红金。
  • 不要把每个按钮都做成双主色渐变，交互层级会混乱。
  • 不要在浅底上使用过重阴影，容易显得模板化。
Accessibility正文使用 Graphite 或 Ink，不用 Slate 作为长段正文。品牌色用于小字时需要加深到 Jade Deep 或 Cobalt Deep。
Components默认卡片半径 8px，边线 #D8E5ED，阴影轻而短。密集产品界面不使用大圆角玻璃卡片。
Imagery主视觉使用透明钻石、数据曲线、白色空间和冰蓝光，不使用人物、硬币、赌博符号或红绿蜡烛图。
Localization中文物料可以提高标题密度，英文物料可以增加留白，但核心色彩比例不变。
