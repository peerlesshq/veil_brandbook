01 Brand Strategy

One brand, two operating surfaces.

Merxi 的品牌核心不是“下注”，而是“把未来事件变成可读信号”。浅色建立可信和高频阅读效率，深色负责高价值传播、发布会、招商和高级感。

Signal

钻石切面代表信息被市场价格折射、校准和聚合。

Trust

大量白色、清晰表格和克制边框让产品接近金融基础设施。

Momentum

玉青和钴蓝用于行动、确认、概率变化和实时反馈。

Premium

香槟金只作为合作、评级、里程碑和招商场景的少量高光。

Minimum size

App / web icon 不小于 24px；招商物料不小于 14mm；社媒头像保留 18% 外边距。

Background

浅底使用白色或 Pearl；深底使用 Ink，不在复杂照片上直接放置 Logo。

Do not modify

不重绘切面、不改变色相、不增加博彩红绿、不把 Logo 拉伸成菱形外框。

03 Icon System

Light and Dark icons are a controlled pair.

Merxi 的 Icon 系统必须像国际一线产品一样稳定：Light icon 负责默认可信界面，Dark icon 负责暗色系统、发布会、深色社媒头像和高级传播。两者共享同一钻石切面、同一颜色逻辑、同一安全区，不允许变成两套不同 Logo。

Light Mode IconPearl surface
Dark Mode IconDeep Ink surface

Clear Space

Icon 外侧至少保留画布宽度 18% 的安全区；社媒圆形裁切时，钻石主体不得超过圆形可视区的 72%。

Minimum Size

App / Web 常规不小于 24px；favicon 16px 只使用简化识别，不承载细节；印刷物料不小于 14mm。

Keyline

Light icon 在白底上必须保留浅灰蓝边线；Dark icon 在深墨底上必须有 1px 亮边或阴影分离。

Social Crop

所有社媒头像优先按 1024x1024 出主文件；圆形头像检查 400、320、180、64 四档裁切。

Do Not

不要旋转、拉伸、重绘切面、加红绿涨跌色、放在低对比照片上，或把 Light/Dark icon 混成第三种版本。

Export

生产文件至少保留 PNG 1024、512、256、128、64、32；如做 favicon，应另行准备简化小尺寸版本。

Icon-led KV Applications

KV 中 Icon 不是角标，而是“市场信号”的视觉锚点。深色 KV 使用 Dark icon 或发光钻石，浅色产品 KV 使用 Light icon 与大留白。

Flat Graphic Design

平面设计里 Icon 可以作为主视觉、辅助图案、徽章、封面元素和数据曲线锚点，但每张画面只允许一个主 Icon 焦点。

05 Color Combination Standards

Build every surface from controlled recipes.

大厂品牌系统不会让设计师“凭感觉取色”。Merxi 的组合标准以场景为单位：先确定底色，再确定文字层、行动层、信号层和少量高级高光。每个组合都必须能跨 App、官网、社媒、Deck 和线下复用。

Light Trust Recipe

默认产品、官网正文、长表格、帮助中心。白色和 Pearl 占绝对主导，Jade 只出现在关键操作。

Dark Premium Recipe

发布会、招商封面、线下屏幕和品牌大片。深墨作为舞台，Jade/Cobalt 作为信号光，Gold 只做高级边缘。

Product Action Recipe

筛选、CTA、概率变化、选中态。Cobalt 负责焦点，Jade 负责确认，不用红绿承担品牌行动。

Data Semantic Recipe

图表、涨跌、预测曲线。红绿不进入主视觉，只作为小面积数据语义和地区化市场规则。

Asia Growth Recipe

小红书、公众号、活动邀请和移动增长素材。画面更亮，留白更大，避免过暗和过度 Web3 霓虹。

Investor Recipe

融资材料、合作提案、招商手册。白纸感保证可信，深墨做结构，Gold 表达资质和合作层级。

06 Color Application Standards

Apply the palette by business context.

同一套颜色在不同业务场景里有不同职责。下面 6 张 Image2 应用图把产品、传播、社媒、线下、数据语义和组合矩阵拆开，方便后续直接变成设计团队的执行规范。

Product Light Surface

核心 App / Web 默认使用。适合行情列表、市场详情、预测曲线、交易确认和用户资产页。

  • BaseWhite / Pearl 作为主背景，Graphite 承载数字和标题。
  • AccentJade 做确认，Cobalt 做焦点，Gold 只在高级模块出现。
  • Avoid不要把整屏做成蓝色或绿色，不要用红绿表达品牌按钮。

Dark Premium Campaign

品牌大片、发布会 KV、线下主屏、融资封面和高价值招商物料使用。

  • BaseDeep Ink 占主导，保留足够暗场给标题和 Logo。
  • AccentJade/Cobalt 是信号光，Champagne 只用于高价值节点。
  • Avoid不要把光效做成彩虹、紫蓝霓虹或游戏感粒子。

Social Format System

覆盖 Square、Story、Banner 和缩略图。每张图只允许一个主视觉焦点、一个主标题和一个数据锚点。

  • Light用于亚洲增长、公众号、小红书、产品功能发布。
  • Dark用于 X、LinkedIn、发布会预热、行业洞察。
  • Gold只用于合作、奖项、融资、白名单和会员权益。

Offline & Investor Materials

把深色舞台和浅色纸面统一起来：屏幕用 Dark Premium，桌面物料用 Light Trust。

  • Screen深墨底 + 钻石信号 + 少量 Jade/Cobalt 线条。
  • Print白底、细线、低饱和图形，保证打印和拍照都干净。
  • Avoid不要让线下物料满版发光，也不要把 Gold 大面积铺底。

Market Data Semantics

预测市场的颜色必须区分“品牌色”和“数据语义色”。红绿只为涨跌和地区习惯服务。

  • Global默认绿涨红跌，适合欧美和国际化金融语境。
  • East Asia中国、日本、韩国等市场可启用红涨绿跌。
  • Avoid不要把红绿放进 Logo、KV、主导航或品牌背景。

Combination Matrix

作为设计团队起稿前的颜色决策板：先选场景组合，再进入 UI、KV、Deck 或社媒模板。

  • ChooseTrust / Premium / Action / Semantic 四类之一，不混用所有颜色。
  • Scale大面积只给背景和结构色，小面积给信号和状态。
  • Review每张图检查是否博彩化、币圈化、过度霓虹化。

12 Governance Rules

Keep it international, not generic.

这是落地时最关键的品牌治理：既要适合亚洲移动用户，也不能在欧美市场显得本地化过重或博彩化。

Do

  • 用 Light Mode 承载核心产品和高频阅读。
  • 用 Dark Mode 做品牌大片、招商、发布会和线下屏幕。
  • 将红绿限制在市场涨跌语义层，并按地区切换。
  • Logo 始终使用 Light Mode 版本的钻石 App icon。
  • 多语言排版优先保证 CJK 字重、行高和数字对齐。

Do not

  • 不要把红色、绿色或金色设为主品牌底色。
  • 不要使用赌场、筹码、扑克牌、火焰、彩虹霓虹等视觉符号。
  • 不要在 Image2 图里生成真实 Logo 或长段品牌文案。
  • 不要为了“科技感”牺牲表格、数字和按钮的清晰度。
  • 不要把中文、日文、韩文字体全部压到英文 display 字体里。
