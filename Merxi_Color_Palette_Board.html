01 Brand Strategy

Merxi 的品牌不是“下注”，而是“让不确定性变得可读”。视觉系统要同时服务交易、研究、招商、社媒增长和线下活动。

02 Logo and Icon

当前图像资产用于确定材质、光感和方向。正式生产时，建议把钻石图形矢量化，建立单色、双色、深底、浅底和 App icon 五套版本。

Master mark

保持菱形比例稳定。切面可以有材质变化，但轮廓必须足够清晰，保证 24px 小尺寸仍能识别。

  • 优先使用深底彩色 icon。
  • 浅底使用钴蓝/玉青双色线性版本。
  • 招商材料可加入少量 champagne 金属切面。

Clear space

Logo 四周至少保留一个钻石短边的 1/2 作为安全空间。不要让文字、按钮、图表或人物靠近切面高光。

03 Color System

主品牌色避开红绿交易语义；红绿只作为本地化市场状态。品牌核心由 Ink、Jade、Cobalt、Metal 和 Pearl 构成。

Color ratio

大公司品牌系统里，比例比颜色本身更重要。Merxi 应该让 Ink/Pearl 负责秩序，Jade/Cobalt 负责信号，Gold 只负责高端和稀缺。

04 Typography

英文使用现代 grotesk/sans，中文使用高可读系统黑体。标题要克制有力，交易界面文字要紧凑清晰。

05 Imagery System

图像系统的核心是“diamond as signal”。每张图像都应该有信息结构：负空间、信号主体、概率曲线、玻璃 UI 或微网格。

Hero image

官网首屏、品牌封面、发布会背景。

Brand pattern

用于 slide divider、网页 section、包装纹理、背景层。

Composition

主体偏右或居中偏上，保留 30-45% 负空间给中英文字和 CTA。

Lighting

深墨底、边缘高光、低饱和金属反射。避免彩虹、烟雾和过度粒子。

Data layer

概率曲线、微点阵、玻璃卡片可以出现，但不得有乱码、假数字或可读假文案。

06 Product UI

App 需要比品牌海报更轻、更清晰。浅色模式用 Pearl，关键动作用 Cobalt，数据活跃状态用 Jade，交易涨跌色按地区切换。

Light mode product surface

高频阅读和交易默认使用浅色界面。

Primary action

买入、确认、创建市场等关键操作使用 Cobalt。不要用 Gold 做按钮。

Probability signal

概率曲线和活跃市场使用 Jade，与涨跌色分离。

Surface density

卡片半径 8px 内，信息密度适中，避免营销卡片堆叠。

Localization

Up/Down 颜色地区化，同时保留箭头和文字，颜色不能是唯一线索。

07 Social Media System

社媒标准要可复用：同一组资产支持 X/LinkedIn、Instagram、微信、小红书、Telegram 和招商转发。原则是“强主视觉 + 清晰留白 + 可替换文字区”。

Feed open

1:1 方图，右侧/上方留白多，适合观点、公告、招商摘要。

  • 文字占比 18-28%。
  • 标题最多 2 行。
  • 适合中英双语版本。

Feed signal

1:1 方图，信息密度更高，适合市场洞察、趋势回顾和数据报告。

  • 避免真实红绿 K 线。
  • 保留底部品牌标签区。
  • CTA 用 Cobalt。

Story and reel

9:16 竖版，上方 25% 留给标题，中段放钻石信号，下方放 CTA 或二维码。

Banner and header

适合 X header、LinkedIn banner、官网 section、招商 deck opening。左侧留给标题，右侧放钻石信号。横幅文字不要超过 14 个英文词或 18 个中文字符。

  • X/LinkedIn：主标题 + 一句副标题。
  • 官网：可叠加导航和 CTA。
  • 活动：可裁成 16:9 或 21:9。

08 Offline and Investor Deck

线下和招商材料应该更“少而贵”：深墨大面积、钻石主视觉、细金线和低饱和灯光。不要做加密展会式霓虹堆叠。

Event booth

适合展台、发布会、品牌墙、VIP lounge。

Investor background

适合招商 PPT、封面、章节页和路演屏幕。

Deck cover

深底图像 + 白色标题 + Jade 小标题。Gold 只做分割线或标签。

Print

浅底单页使用 Pearl 背景，图像裁切为 40-55% 面积，避免全黑耗墨和阅读疲劳。

Spatial

展台使用大面积主视觉和低密度信息，禁止把 App 截图、数据和招商文字堆满墙面。

09 Standards and Misuse

品牌要规模化，就需要清晰的边界。下面是建议写进 brand guideline 的正反标准。

Do

  • 用 Ink/Pearl 控制画面秩序，用 Jade/Cobalt 传达信号和行动。
  • 让钻石图形保持清晰轮廓，避免过度材质化。
  • 社媒模板保留固定留白区，便于中英双语替换。
  • 交易色使用地区化 token，并搭配文字和箭头。
  • 招商材料使用更深、更克制、更高级的光线。

Do Not

  • 不要把红绿作为主品牌色，也不要在 logo 里加入涨跌色。
  • 不要使用彩虹霓虹、币圈金币、赌场筹码、骰子或体育博彩符号。
  • 不要大面积使用金色，避免奢侈品/博彩促销感。
  • 不要生成带乱码文字的图像作为正式物料。
  • 不要让 UI 卡片圆角过大或卡片套卡片，避免 SaaS 模板感。
