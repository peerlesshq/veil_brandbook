Veil / 预测所基础标识系统

以 Veil Aperture 作为核心标识：一个 45° 钻石外框打开出 V 形概率窗口， 表达“隐藏信息被市场揭示为概率”。

Veil Aperture 3D Render Flat SVG Lockups Usage Rules

01 / Generated Assets

3D 用于品牌场景，平面用于正式系统。

3D render 可以进入官网首屏、pitch deck、发布物料；正式 logo 则以 SVG 平面系统为准。 这能保证大型公司需要的可缩放、可审查、可复现和多场景一致性。

3D Logo Render

用于高冲击品牌场景。保留玻璃、金属、蓝色和琥珀色信号光，突出“概率棱镜”。 不建议用于小尺寸、合同、法务、favicon 或单色印刷。

Flat SVG System

新版平面系统使用 45° Veil Aperture SVG，避免过度靠近普通珠宝图案。 产品、导航、favicon、app icon 和品牌规范都以这套 SVG 为准。

02 / Master Mark

主标：Veil Aperture。

主标不做普通宝石图案，而是一个打开的概率窗口。外部是钻石边界，内部是 V 形 aperture， 左右辅以 teal 和 amber 两个信号面。

Primary mark: light background

Outline mark: technical / mono contexts

App icon: dark institutional container

03 / Geometry Notes

几何原则。

标识应保持严格对称和 45° 结构。中心 V 是品牌识别核心，不能被细节、纹理或高光吞掉。

Outer Diamond

外轮廓为 45° diamond，代表市场切面、价值压缩和清晰边界。

Central Aperture

中心 V 形窗口代表 Veil 被打开，同时锁定英文首字母 V。

Signal Planes

teal 和 amber 是左右两侧的市场信号面，不是装饰色。使用面积必须克制。

04 / Logo Lockups

标准锁定组合。

第一优先级是英文 Veil，中文“预测所”作为二级描述。中文名不要和英文争夺主视觉权重。

Positive lockup: light background

Reverse lockup: dark background

05 / Clearspace & Size

留白和最小尺寸。

大型公司级 logo system 的核心不是“好看”，而是任何团队拿去用都不会变形、拥挤或失去辨识度。

Clearspace: X = mark width / 6。四周至少保留 1X。

Minimum Size

  • Digital mark: 20px minimum. Below 28px use simplified mark only.
  • Digital horizontal lockup: 112px width minimum.
  • Print mark: 6mm minimum.
  • Print horizontal lockup: 28mm width minimum.
  • App icon: keep central mark optically centered, never crop the diamond.

07 / Usage Rules

使用规范。

这些规则用于保证 Veil 在产品、官网、社交、融资材料和合作物料里保持一致。

Do

  • 优先使用 SVG 平面标识作为正式 logo。
  • 在深色背景使用 reverse lockup。
  • 3D render 只用于品牌主视觉、发布页和 deck 封面。
  • 保持中心 V 清晰，不让纹理或背景干扰。
  • 中文“预测所”作为二级信息，跟随英文 Veil。

Don't

  • 不要拉伸、倾斜、旋转或重绘 diamond mark。
  • 不要把 icon 做成普通珠宝、水晶球、筹码或 K 线。
  • 不要随意增加渐变、高光、阴影或发光边。
  • 不要让 teal 和 amber 大面积主导标识。
  • 不要在低对比背景上使用完整彩色 mark。
